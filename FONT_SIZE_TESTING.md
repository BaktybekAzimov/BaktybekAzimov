# Инструкция по тестированию размеров шрифтов

## Цель
Протестировать все страницы приложения с тремя размерами шрифтов (маленький 14px, средний 16px, большой 18px) и убедиться, что:
- Текст не выходит за границы контейнеров
- Все элементы интерфейса отображаются корректно
- Нет визуальных багов или наложений
- Читабельность остается на хорошем уровне

## Как запустить приложение для тестирования

```bash
cd truck-tracker
npm run dev
```

Приложение откроется на `http://localhost:5173`

## Как переключать размеры шрифтов

1. Войдите в систему (например, admin@demo.com / password)
2. Перейдите в **Settings** (Настройки)
3. В разделе "Размер шрифта" выберите один из вариантов:
   - **Маленький** (14px)
   - **Средний** (16px) - по умолчанию
   - **Большой** (18px)
4. Размер шрифта применяется мгновенно ко всему приложению

## Страницы для тестирования

### 1. Login (Страница входа)
**URL**: `/login`

**Что проверить на каждом размере:**
- [ ] Заголовок "TruckTrack" не обрезается
- [ ] Подзаголовок "Система учёта рейсов грузовиков" помещается
- [ ] Поля Email и Пароль отображаются корректно
- [ ] Кнопка "Войти" правильного размера
- [ ] Демо учетные данные читабельны
- [ ] Все элементы помещаются в карточке

### 2. Dashboard (Главная страница)
**URL**: `/dashboard`

**Что проверить на каждом размере:**
- [ ] Заголовок "Дашборд" отображается корректно
- [ ] Все 4 статистические карточки:
  - Общая выручка
  - Всего рейсов
  - Чистая прибыль
  - Средняя прибыль
- [ ] Цифры в карточках не обрезаются
- [ ] Графики (Revenue Chart, Routes Chart) масштабируются
- [ ] Таблица "Последние 10 рейсов":
  - Заголовки колонок
  - Данные в ячейках
  - Статусы рейсов
- [ ] Фильтры (Сегодня, Неделя, Месяц, Всё время)

### 3. Trips (Рейсы)

- [ ] Кнопка "Добавить рейс"

  - Текст "Aa" в каждой карточке

  - Активная карточка подсвечивается
  - При переключении размер меняется во всем приложении
- [ ] Раздел "Типы расходов":
  - Список тегов
  - Input для добавления
  - Кнопки удаления
- [ ] Кнопка "Сохранить изменения"

  - "Система учета" (первая строка)

- [ ] Все пункты меню:
  - Dashboard

  - Водители
  - Машины
  - Маршруты

  - Настройки

- [ ] Иконки и текст выровнены

**Закрытое состояние:**
- [ ] Только иконки видны
- [ ] Tooltip появляется при наведении
- [ ] Tooltip читабелен

### 10. Header (Шапка приложения)
**На каждой странице:**
- [ ] Название текущей страницы
- [ ] Subtitle (если есть)

  - Переключатель темы (светлая/темная)

- [ ] Текст в dropdown не обрезается

## Комбинации для проверки

### Минимальный набор тестов:
1. **Small (14px)** - Dashboard + Settings + Users
2. **Medium (16px)** - Trips + Drivers + Vehicles
3. **Large (18px)** - Routes + Login + Settings

### Полный набор тестов:
Пройдите **все 10 страниц** с **каждым из 3 размеров** = 30 комбинаций

- [ ] **Chrome/Edge** (основной браузер)
- [ ] **Firefox**
- [ ] **Safari** (если на Mac)

Протестируйте на разных разрешениях:
- [ ] **Desktop** (1920x1080 или больше)
- [ ] **Laptop** (1366x768)
- [ ] **Tablet** (768px ширина) - откройте DevTools и переключитесь в responsive mode
- [ ] **Mobile** (375px ширина) - откройте DevTools и переключитесь в responsive mode

## Темы

Протестируйте оба режима:
- [ ] **Светлая тема** (Light mode)
- [ ] **Темная тема** (Dark mode)

## Известные проблемы для проверки

Обратите особое внимание на:
1. Длинные email в таблице Users
2. Длинные названия маршрутов в таблице Routes
3. Название приложения в Sidebar (должно быть на 2 строках)
4. Статусы в таблицах (badges)
5. Кнопки с иконками
6. Числа с большим количеством разрядов (например, выручка)

## Что делать при обнаружении проблем

Если вы нашли проблему:
1. Сделайте скриншот
2. Запишите:
   - Страницу
   - Размер шрифта
   - Разрешение экрана
   - Браузер
   - Описание проблемы
3. Создайте issue в репозитории или сообщите разработчику

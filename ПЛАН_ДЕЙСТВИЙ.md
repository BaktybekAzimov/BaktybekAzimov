## 📊 КАК РАБОТАЮТ РАСЧЁТЫ

### Автоматические расчёты в БД:
```sql
total_costs = fuel_cost + maintenance_cost + other_costs
net_profit = revenue - total_costs
driver_payment = net_profit * 0.3  (30% водителю)
owner_payment = net_profit * 0.7   (70% владельцу)
```

### Пример:
```
Выручка:           50 000 с
Топливо:          -15 000 с (30%)
Обслуживание:      -3 000 с (6%)
Другие расходы:    -2 000 с (4%)
─────────────────────────────
Общие расходы:    -20 000 с (40%)
Чистая прибыль:    30 000 с (60%)
─────────────────────────────
Водителю (30%):     9 000 с
Владельцу (70%):   21 000 с
```

## ❓ ЧАСТЫЕ ВОПРОСЫ

### Q: Как добавить нового пользователя?
**A:**
1. Supabase Dashboard → Authentication → Users
2. Add user → введите email + пароль
3. После создания → SQL Editor:
```sql
UPDATE auth.users
SET raw_user_meta_data = raw_user_meta_data || '{"role": "admin"}'::jsonb
WHERE email = 'новый@email.com';
```

### Q: Как изменить процент выплаты водителю?
**A:** Сейчас это жёстко прописано в схеме БД (30%/70%). Чтобы изменить:
```sql
-- Изменить формулы в таблице trips
ALTER TABLE trips
  DROP COLUMN driver_payment,
  DROP COLUMN owner_payment;

-- Пересоздать с новыми процентами (например 40%/60%)
ALTER TABLE trips
  ADD COLUMN driver_payment NUMERIC(10, 2) GENERATED ALWAYS AS (
    (revenue - (fuel_cost + maintenance_cost + other_costs)) * 0.4
  ) STORED;
```

### Q: Как сделать резервную копию?
**A:**
Supabase Dashboard → Database → Backups → Download backup

Или через SQL:
```bash
pg_dump -h db.xxxx.supabase.co -U postgres -d postgres > backup.sql
```

### Q: Приложение не загружается, белый экран
**A:**
1. Откройте Console (F12)
2. Проверьте ошибки
3. Убедитесь что Supabase URL и Key правильные в .env
4. Перезапустите: `npm run dev`

### Q: Как развернуть на продакшн?
**A:**
1. **Vercel** (бесплатно):
```bash
npm install -g vercel
vercel
```

2. **Netlify**:
```bash
npm run build
netlify deploy --prod --dir=dist
```

3. Добавить переменные окружения (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY)
